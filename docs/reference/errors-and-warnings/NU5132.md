# NuGet Warning NU5132

> The zip format supports a limited date range.
> The following files are outside the supported range:
>
> 'lib/net10.0/Example.dll' changed from '12/31/1979' to '1/1/1980'

## Issue

One or more files you're packing have a last-write timestamp outside the range supported by the ZIP format.
NuGet checks the timestamps in UTC against these limits:

- January 1, 1980, at 00:00:00 UTC.
- December 31, 2107, at 23:59:58 UTC.

NuGet changes each affected file's timestamp in the package to the nearest supported limit and lists the changes in the warning.
It doesn't change the original source file's timestamp.

## Solution

Check the last-write timestamps of the files listed in the warning.
To prevent the warning, update the affected source files to use timestamps within the supported range, and pack again.

If the adjusted timestamps in the package are acceptable, no changes are needed.
