# NuGet Warning NU5052

> The package ID 'PackageId' does not adhere to the restricted set of characters. The ID must only contain ASCII letters, digits, dots ('.'), and dashes ('-'). It must start with a letter or digit, and must not contain consecutive dots or dashes.

## Issue

Your package ID contains characters that don't comply with the NuGet package ID standards.
Valid package IDs must follow these rules:

- Only use ASCII letters, digits, dots (`.`), and dashes (`-`).
- Start with a letter or digit.
- Don't contain consecutive dots (`..`) or consecutive dashes (`--`).
- Be 100 characters or fewer.

This warning is raised during `dotnet pack` or `nuget pack` when the package ID in your project or `.nuspec` file violates one or more of these rules.

## Solution

Update the `PackageId` property in your project file or the `<id>` element in your `.nuspec` file to use only allowed characters.

For example, if your project file contains an invalid character:

```xml
<PropertyGroup>
  <PackageId>My@Package</PackageId>
</PropertyGroup>
```

Change it to a valid ID:

```xml
<PropertyGroup>
  <PackageId>My.Package</PackageId>
</PropertyGroup>
```

If you're using a `.nuspec` file, update the `<id>` element:

```xml
<package>
  <metadata>
    <id>My.Valid-Package</id>
  </metadata>
</package>
```

For more information about the package ID restrictions, see [NuGet package ID standards](https://github.com/NuGet/Announcements/issues/75).
